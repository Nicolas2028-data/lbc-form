新しい作業を開始します。

## 手順

1. 今日の日付を `YYYYMMDD` 形式で取得する
2. `.steering/[日付]-$1/` ディレクトリを作成する
3. 以下の3ファイルを作成する

### requirements.md

```markdown
# 要求内容

作成日:[日付]
作業名:$1

## 何をするか

(1〜2文で。この作業のゴール)

## 背景

(なぜこの作業が必要か)

## 変更・追加する機能

-

## 受け入れ条件

(何ができたら完了とみなすか)

- [ ]
- [ ]

## 制約事項

(守らなければいけないこと)

-

## Nicolas への確認が必要な事項

(なければ「なし」)

-
```

### design.md

```markdown
# 設計

## 実装アプローチ

(どう作るか)

## 変更するファイル

| ファイル | 変更内容 |
|---|---|
| | |

## スキーマの変更

(スプレッドシート台帳・Notion DB の変更がある場合。なければ「なし」)

## 影響範囲

(この変更で影響を受ける既存の機能)

-

## SPEC.md 7原則との整合

- [ ] シートが正 / Notion 表示専用の原則を守っているか
- [ ] 台帳は追記専用の原則を守っているか
- [ ] 冪等性(requestId)が担保されているか
- [ ] 認可はサーバー側にあるか

## 検討した他の案

| 案 | 採用しなかった理由 |
|---|---|
| | |
```

### tasklist.md

```markdown
# タスクリスト

## 進捗

0 / 0 完了

## タスク

- [ ]
- [ ]

## 完了条件

-

## メモ

(作業中に気づいたこと)
```

## 作成後

- requirements.md を埋めて **Nicolas の確認を得る**
- 確認後、design.md を埋める(必要なら architect を呼ぶ)
- design.md も **Nicolas の確認を得てから** 実装に入る

**確認を飛ばして実装を始めないでください。**
