今日の作業を報告としてまとめます。

## 手順

### 1. 情報を集める

以下を確認してください。

| 情報源 | 見るもの |
|---|---|
| `git log --since="today"` | 今日のコミット |
| `.steering/` の tasklist.md | タスクの進捗 |
| 作業中のファイル | 変更内容 |
| `TASKS.md` | 全体進捗の変化 |

### 2. レポートを作成する

`reports/YYYY-MM-DD.md` に以下の形式で保存します。

```markdown
# 作業報告 YYYY-MM-DD

## 今日やったこと

-
-

## 進捗

現在の作業:[.steering/ のディレクトリ名]
タスク:X / Y 完了

TASKS.md 全体:N / 46 完了

## 動くようになったもの

(staging または本番で動作確認できたもの)

-

## 詰まっていること

(なければ「なし」)

-

## Nicolas への確認事項

-

## 明日やること

-

## 現状に対する所感

(順調か、遅れているか、率直に書く)
```

### 3. 報告する

作成したレポートの要点を、チャットにも短く表示してください。
ファイルを見に行かなくても状況が分かるようにします。

## 書き方

- **率直に書いてください。** 遅れているなら遅れていると書く
- できなかったことも書く
- 「順調です」で済ませない。何が順調なのかを書く
