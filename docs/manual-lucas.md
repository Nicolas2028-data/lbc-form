      ↓
[「本日カルテ作成」ボタンをタップ（1タップ）]

## 1. 施術記録の入力手順（通常）

### ＜Notion の未記録リストから開く場合（推奨）＞

1. Notion の「📋 LBC 運用ダッシュボード」を開く
2. **🚨 未記録リスト** に本日来店した患者の一覧が表示される
3. 患者カードの **「📝 記録する」** リンクをタップ
   → 施術記録シートが自動で開き、名前・電話番号が入力済みになっている
4. パスワードを入力して「ログイン」をタップ
5. **施術有無** を選択：
   - **✅ 施術を受けた** → 通常の記録入力へ
   - **⚫ 施術を受けなかった** → 理由を入力（急用でお帰り、体調不良で中止 など）
6. 施術を受けた場合、以下を入力：
   - **施術コース**（必須）
   - **支払い方法**（必須）
   - **売上金額**（自動計算されるが確認が必要）
   - **施術メモ**（任意）
7. 「記録する」ボタンをタップ → 「✅ 記録しました。1分以内に Notion に反映されます」が表示されたら完了
8. 1分ほど待つと、未記録リストからこの患者のカードが消える

### ＜検索から開く場合（従来通り）＞

1. iPadまたはスマートフォンで **施術記録シート** を開く
   → URL: `https://nicolas2028-data.github.io/lbc-form/treatment-record.html`
2. パスワードを入力して「ログイン」をタップ
3. **今日の未記録患者** に患者名が表示されている場合は、そちらをタップして選択
   - 表示されていない場合は、検索ボックスに名前・フリガナ・診察番号を入力して選択
4. 画面が切り替わり、患者バナー（名前・診察番号・来院回数）が表示される
5. 上記 5〜8 と同じ手順で入力・送信

## 1.5. 2回目以降のお客様の受付フロー（Notion 使用）★2026-09-27 追加

**2回目以降のお客様は問診票を使いません。** Notion だけで受付から記録まで完結させます。

### 手順

1. Notion の **「👥 顧客管理DB」** を開く
2. 検索ボックスに来店客の名前（またはフリガナ・診察番号）を入力して顧客ページを開く
3. 顧客ページ内の **「本日カルテ作成」ボタン** を1回タップする
   → 施術カルテDB に新規カルテが自動作成される（施術カルテDBの **🚨 未記録** ビューにも出る）
   → 1分以内に GAS が診察番号と「📝 記録するURL」を自動で埋めます
4. 患者に **「前回から体の変化はありますか？」** と口頭で確認する
5. 新規カルテを開き、**「前回から変化」** プロパティを **変化なし** / **変化あり** のいずれかにタップして設定
6. 施術を実施
7. 施術後、同じカルテを開いて以下を入力する：
   - **施術コース**（必須）
   - **売上金額**（必須）
   - **支払い方法**（現金 / カード / PayPay / 未払い）
   - **施術メモ**（任意）
   - **ステータス** を **✅ 完了** に変更
8. 1分以内に GAS がシート台帳（施術台帳）へ自動反映します

### 別の入力方法（従来の記録シート経由）

Notion 上でプロパティを埋める代わりに、カルテ内の **「📝 記録する」** リンクをタップすると、従来の施術記録シート（treatment-record.html）が開きます。そちらで入力しても結果は同じです（名前・電話・診察番号は事前入力済みです）。

### 注意事項

- 「本日カルテ作成」ボタンは、**その日の受付につき1回のみ** 押してください（重複して押すと同日カルテが2枚できてしまいます）
- 「前回から変化」のタップは check-in タイミング（施術前）に行うと、施術中の会話に集中できます
- 記録漏れは **🚨 未記録リスト** に赤で残ります。当日中にゼロにする運用を目指してください

## 2. 間違えたときの直し方（訂正モード）

### ＜当日の記録を取り消すとき＞

施術記録を入力した**同日中**であれば、画面上で取り消しが可能です。

1. 患者を選択すると、「📋 本日の記録」セクションが表示される
2. 取り消したい記録の横の **「取消」ボタン** をタップ
3. 確認ダイアログが表示されるので「OK」をタップ
4. 「記録を取り消しました」と表示されれば完了
5. 必要であれば、正しい内容で再度「記録する」ボタンから入力する

**注意事項：**
- 取り消しは **当日のみ** 可能です。翌日以降は後述の手動赤伝方式になります
- 取り消し後も患者の「来院記録」（Notionのカルテページ）は残ります（医療記録として保持）
- 売上金額・クレジット使用の帳簿上の訂正のみが行われます

### ＜過去日の記録を訂正するとき（手動赤伝）＞

翌日以降の修正は、Googleスプレッドシートの「施術台帳」に**手動で赤伝行**を追記します。

1. 台帳スプレッドシートの「施術台帳」シートを開く
2. 訂正対象の行の `記録ID` をコピー
3. 最終行に以下の内容で新しい行を追記する：

| 列 | 内容 |
|----|------|
| 記録ID | 新しいUUID（任意のIDでOK） |
| 種別 | `void` |
| 対象記録ID | 訂正対象の記録ID |
| 施術日 | 元の施術日 |
| 診察番号 | 元の診察番号 |
| コース・売上 | 元の値を**マイナス**にする |
| 集計対象 | `FALSE` |

4. 必要なら正しい内容で「種別=record」の行を追加する
5. ニコラスに連絡して確認を依頼する（不明な点がある場合）

## 3. 問診票 iPad 運用手順（初回来院のお客様専用）★2026-09-27 更新

**問診票は初回来院のお客様専用のフォームです。** 2回目以降のお客様は問診票を使わず、Notion で完結させてください（本マニュアル 1.5 参照）。

1. iPad で **問診票** を開く
   → URL: `https://nicolas2028-data.github.io/lbc-form/questionnaire.html`
2. 言語を選択（日本語 / Español / Português）
3. 電話番号や名前などの全項目を入力してもらう
4. 問診票を記入してもらい、同意書に署名してもらう
5. 「問診票を送信する」ボタンをタップ → 「問診票を受け付けました！」が表示されたら完了

### エラーが出た場合

- **「この電話番号は既に登録されています。受付にお声がけください」**
  → その電話番号は既存患者のものです。問診票では受付できないので、Notion の顧客管理DB から検索して **1.5 の 2回目以降フロー** で受付してください
- 通信エラー・サーバーエラーは 5章「困ったとき」を参照

**廃止済み機能（2026-09-27）:** 「初めて / 2回目以降」選択カード、電話番号のみでの再来院照合、問診票のコース選択、前回から変化ラジオ、患者情報確認・編集カードは削除しました。

## 4. ダッシュボードの見方と運用ルール

### Notion ダッシュボード（2026-09-27 更新）

トップに **📋 LBC 運用ダッシュボード** ページがあります。以下のセクションを1日の運用の中心にしてください。

**🚨 未記録リスト（最重要）**
- 施術カルテDB の中で、まだ施術記録が完了していない（ステータス=🔴 未記録 の）カルテの一覧
- 初回のお客様（問診票送信）と 2回目以降のお客様（「本日カルテ作成」ボタン起動）の両方がここに集まります
- 色分け：
  - 🟢 **本日**（緑）: 今日のカルテ。当日中に記録すればOK
  - 🟡 **1日経過**（黄）: 昨日以前の書き忘れ。すぐ記録する
  - 🔴 **2日以上**（赤）: 対応漏れ。急いで記録する
- 各カードの「📝 記録する」リンクから直接施術記録シートが開けます（Notion で直接プロパティを埋めてもOK）
- 空になったら「🎉 ALL DONE!」の表示

**📅 今日の来店**
- 今日カルテが作成された全患者（記録済み含む）のギャラリー表示

**📊 数字で見る運用**
- 従来の Chart.js ダッシュボードを埋め込み表示

**👥 顧客管理 DB（旧: 顧客マスタ DB）**
- 患者一覧。電話番号・言語・クレジット残高を確認できる
- **2回目以降のお客様は、ここで検索して「本日カルテ作成」ボタン** を押します（1.5 参照）

**📋 施術カルテ DB**
- 各患者の来院ごとのカルテ。問診内容・コース・売上が自動反映される
- **「前回から変化」プロパティ** は check-in 時にワンタップで設定してください

**重要ルール：**
> **Notion のデータは直接編集しないこと。**
> シート（スプレッドシート）が「正」のデータです。Notion は表示専用ダッシュボードです。
> Notion を直接編集しても、次の同期サイクルでシートの内容に上書きされる場合があります。

### Google スプレッドシート（台帳）

- **顧客マスタ：** 患者マスタ。ステータスを `archived` にすると検索・同期から除外される
- **施術台帳：** 施術記録。**既存行は書き換えない**（追記専用）
- **クレジット台帳：** クレジット増減履歴。**既存行は書き換えない**（追記専用）

## 5. 困ったとき

### 送信が失敗した場合

- 「通信エラーが発生しました」が表示された場合：ネット接続を確認して再送してください
- 「サーバーエラー」が表示された場合：しばらく待ってから再送してください
- 何度やっても送信できない場合：ニコラスに連絡してください

### パスワードがわからない場合

ニコラスに連絡してください。GAS の管理画面からパスワードを確認・変更できます。

### ログインが「ロックされました」と表示された場合

パスワードを5回以上間違えると15分間ロックされます。15分後に再度お試しください。
それでもログインできない場合はニコラスに連絡してください。

### Notion に反映されていない場合

自動同期は約1分ごとに実行されます。少し待ってから確認してください。
それでも反映されない場合は、スプレッドシートの「[エラー回数]」列を確認し、5以上の行があればニコラスに連絡してください。

### ニコラスへの連絡基準

以下のような場合は必ずニコラスに連絡してください：
- 同じ患者が重複して登録されている
- クレジット残高が合わない
- 複数日分のデータが Notion に反映されていない
- 患者の電話番号が変わった（統合作業が必要）

## 6. no-show（施術しなかった）の記録方法

お客様が来院したものの施術を受けずに帰った場合も、必ず記録してください。未記録リストから消えず、記録漏れとして残ってしまうためです。

1. Notion の未記録リストから該当患者の「📝 記録する」をタップ
2. パスワード入力後、**施術有無** で「⚫ 施術を受けなかった」を選択
3. 理由を入力（例：
   - 「急用が入って帰宅」
   - 「体調不良で中止」
   - 「予約時間を大幅に過ぎたためキャンセル」
   - 「本日は相談のみで施術なし」
   ）
4. 「記録する」をタップ → 完了

no-show として記録された患者は：
- 売上・来院数の集計対象からは自動的に外れます
- Notion のカルテには「⚫ 施術なし」として残ります
- 理由がメモとして残ります
